# Avaliação de IA, Linguística e Anotação de Dados

### 🚀 Ferramentas e Competências em IA
Como parte do meu trabalho com avaliação de modelos de linguagem, utilizo diariamente:

* *Avaliação de LLMs:* Análise crítica de respostas geradas por IA, verificação de fatos e alinhamento de intenção.
* *Ferramentas de Anotação:* Experiência prática em plataformas de rotulagem e curadoria de dados para treinamento de modelos.
* *Prompt Engineering:* Criação e teste de prompts para otimizar o desempenho e a precisão das IAs.
* *Qualidade Linguística:* Garantia de fluidez, tom de voz e adequação cultural (PT-BR/EN).
